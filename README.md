## 🌟 Overview

**NY.Portfolio** is a high-performance, futuristic portfolio website designed for an **AI & ML Systems Engineer**. It features interactive 3D particle nodes, dynamic system architecture charts, real-time GitHub contribution heatmaps, and a cyberpunk terminal aesthetic.

- 🌐 **Live Website**: [https://portfolio-two-ashy-qzoc8vj3e0.vercel.app](https://portfolio-two-ashy-qzoc8vj3e0.vercel.app)
- 👤 **Developer**: Yatharth Nagpal ([@Yatharthnagpal](https://github.com/Yatharthnagpal))
- 📍 **Location**: New Delhi, India

---

## 🚀 Key Features

- 🧠 **Interactive System Architecture Charts**: Visual node flow diagrams & 100% compute/latency distribution bar charts for every AI/ML project.
- 🐙 **Live GitHub Heatmap**: Real-time contribution grid fetched directly from the GitHub API.
- 🪐 **Orbital Tech Cosmos**: Dynamic floating tech badges with smooth interactive hover effects.
- 💚 **Cyberpunk Dark Theme**: Tailored HSL green glowing aesthetics (`#22C55E` & `#0A0F0D`) with glassmorphism overlays.
- 📱 **Fully Responsive**: Mobile-first fluid design across all device viewports.
- ⚡ **Optimized Performance**: Pre-rendered Next.js App Router pages with instant static generation.

## ⚙️ Local Development

To run this portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Yatharthnagpal/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000).
